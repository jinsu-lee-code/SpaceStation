# 모델링 06b — 진화 모듈 내부 템플릿 ② 2단계 개방형 방 (그리드 허브 · 궤도 미러 · 융합 플랜트 · 아콜로지 · 대형 토러스 · 시민 회관 · 치안 본부 · 바이오돔 · 식량 공장)

> 원래 `MODELING.md` 7-11절 가운데 (314 ~ 362줄)를 그대로 옮김 (2026-11-11 분할). 아래 하위 항목은 모두 "2단계 개방형 방" 항목에 딸림 (06c로 이어짐). 매번 확인할 항목은 [00-checklist.md](00-checklist.md).

- **2단계 개방형 방** (첫 사용 = 그리드 허브 `gd_builder`, 키트 = `evo2_kit` · `evo2_kit_builder` → `SM_InteriorKit_Evo2.fbx`):
  - 하늘 = `INT_{이름}_Sky`: 차지한 칸만 둘러싼 안쪽 면 껍질 (`evo2_sky` — 이웃 칸 위로 나가면 안 되므로 T자 등 꺾임 그대로), 재질 Evo2Sky = 창 셰이더 (Tint 흰색 · Rim 검정 · Streak 0). `InteriorExteriorView`가 창으로 다뤄 바깥이 진짜로 보이고 이웃 방 내부를 가림. 충돌체 없음 → 걸음은 난간 유리 `_Glass`가 막음 (점프 없음). 그래서 **자홍 뚫림 검사는 껍질을 켠 채로 돌림** (대조로 껍질을 끄면 자홍이 나오는지 한 번 봄) — **단, 유리 · 지붕 안 실내형 방은 껍질을 끄고도 돌림** (껍질을 켜면 뒤에 별이 비쳐 틈을 못 잡음, 8-7)
  - 압력 막 = `_Curtain` 조각 (이름이 `_Shell · _Glass · _Door · _Soft`로 안 끝나서 충돌체 없음), `evo2_kit.arch_veil`로 UV = 아치 기준 미터 (u = 가운데에서 가로, v = 바닥에서 위), 재질 Evo2Curtain = `SpaceStation/PressureVeil`, 재질의 `_Arch` = (반폭, 둥근 부분 시작 높이)
  - 우주복 = `InteriorOpenAir` + `SM_ResidentSuit.fbx`: 실내 구역 원 밖 주민만 입힘. 새 개방형 방은 프리팹에 이 컴포넌트와 실내 원만 넣으면 됨
  - 문 자리 (첫 사용 = 궤도 미러): `evo2_deck(doors=…)`가 난간을 패널 폭 ±1.6만큼 비우고 양옆에 기둥, `evo2_sky(holes=…)`가 하늘 껍질에 문 구멍 (열린 문 너머 통로 튜브가 보이게). 닫힌 자리 = 키트 `KIT_Wall_Evo2` (같은 모양 난간 + 껍질 자리의 하늘 조각 — 보이지 않는 충돌체는 `InteriorBuilder`가 패널 크기로 둠), 열린 자리 = `KIT_WallDoor_Evo2` (사방에서 보이는 둥근 문)
  - 빛 효과는 재질 슬라이더로 조절: 빛기둥 `M_LightShaft` (바깥) · `M_InteriorLightShaft` (내부) = 광량 · 감쇠 · 빛 결 등, 플라즈마 `M_Plasma*` · `M_FusionPlasma` · `M_InteriorPlasma*` = 휘말림 · 대비 · 빛 실. 플레이 중에 바꾸면 바로 보이고 저장됨 (Setup은 처음 만들 때만 값을 넣어 덮어쓰지 않음). 번개 = 바깥 · 내부 모두 `LightningFx` (메시 번개 금지 — 사용자 2026-11-02 "심이 얇아야")
  - 빛줄기 = `LightBeamFx` (3D 빛기둥, 거울 지름 · 면 방향 · 수신기 지름을 넘김). 시안에서 가는 관으로 그리지 말 것 (사용자 2026-11-02 "선 같아 보여서 반사광 느낌이 안 나"). 쉬는 자세의 머리 메시 + `InteriorHeliostat` = 실제 해를 따라 돌고 빛기둥 시작 면도 같이 옮김. 빛줄기는 양옆 낮은 칸 하늘(y 3.95) 밖으로 나가면 껍질 뒤로 숨음 → `om_builder.check_beams`로 줄기 높이를 맞춤
  - 두꺼운 잎은 `evo_kit.leaf_u` 말고 `om_builder._leaf` (leaf_u 첫 줄은 꼭짓점이 겹쳐 두께가 있으면 비다양체로 남음)
  - 동물 몸에 붙는 것은 **쉬는 자세로 재서 본 기준으로 저장** (사용자 2026-11-02 "에어팩이 공중부양"): 지금 자세를 구우면 앉은 주민의 든 꼬리 · 숙인 고개가 치수에 섞임. 동물 FBX는 읽기 꺼짐이라 `sharedMesh.vertices`가 비어 있음 → 본을 바인드 포즈로 돌려 `BakeMesh(mesh, true)` 후 같은 프레임에 되돌림
  - **돔 실내 + 바깥 갑판** (첫 사용 = 융합 플랜트 `fp_builder`): 낮은 벽 + 유리 돔이면 아치(꼭대기 F + 2.76)가 돔 유리를 뚫으므로 짧은 아치 터널 `porches`로 — 안쪽 입구는 아치 꼭대기 높이의 돔 반지름보다 안쪽, 바깥 테는 돔 둘레 길을 막지 않게 벽에서 2cm만, 벽 · 유리는 같은 `door_cuts`로 깎음 (잘린 면은 터널 벽 속). 압력 막은 벽 두께 안 (`CURTAIN_R`) — 우주복 실내 원 반지름과 같게
  - **빛나는 색은 흰색으로 날아감** (사용자 색 그대로 Accent를 쓴 열 관이 흰 관으로 보였음): 색이 뜻을 가진 빛 (열 = 주황)은 Accent 대신 색이 진한 전용 재질 (`M_InteriorEvo2Heat`, 발광 ×1.5). Blender 팔레트 값은 선형이라 Unity `Color`에 그대로 넣으면 어둡게 나옴 → 밝혀서 넣고 사진으로 바깥 모델과 비교
  - 회전체 윗면 · 아랫면을 평평하게 = `crisp(lathe(...))` (`lathe` 기본은 전부 매끈해서 턱이 있는 받침이 부풀어 보임). 위아래로 이어 쌓는 회전체는 맞닿는 면을 겹치게 (아래 몸통 위 끝을 위 테 속으로) — 축 위 가운데 점이 같으면 `clean` 점 병합으로 비다양체. 같은 자리를 깎는 두 덩이는 아래쪽을 1.5cm 더 깎아 잘린 면이 같은 평면에 놓이지 않게
  - 유리 통 속 빛: 납작한 판은 판으로 보임 → 물 덩어리 자체를 은은히 빛나는 반투명 (`M_InteriorEvo2WaterGlow`) + 가는 빛 줄. 거품 나선을 양(+)으로 돌리면 오르는 것처럼 보임 (나선 각이 위로 갈수록 커질 때). 작은 공 속 빛 실은 3.5mm · 꺾인 줄 (굵으면 거미처럼 보임)
  - **가운데가 뚫린 회전체 = `lathe_loop`** (첫 사용 = 아콜로지 `ar_builder`): `lathe`는 양 끝을 면으로 막아 탑 구멍 · 유리 바닥 아래를 가림. 층 사이로 샤프트가 지나는 바닥 · 천장은 모두 `lathe_loop` / `ring`
  - **큰 곡면 유리는 매끈하게 + 하이라이트 끔** (아콜로지 유리 알): 각진 면이면 층층 띠로 어둡게 비치고, 매끈하게 하면 점광원 하이라이트가 긴 띠로 번져 하늘에 혜성처럼 보임 → 전용 재질 (`M_InteriorEvo2EggGlass`)에서 끔. 벽 곡면은 축을 두른 면만 `use_smooth` (문 자른 면은 각진 채로 둬야 문 둘레가 얼룩지지 않음)
  - **둘레에 물건을 돌려 놓을 땐 간격 = 360 / 개수** (아콜로지 타워 다섯을 75°로 놓았더니 마지막 틈만 60°라 구경 자리가 나무 속, 디딤돌이 벤치에 붙음). 층이 여러 개면 서는 자리는 한 층에만 (주민 `PathClear`가 수평으로만 재서 위아래 층 자리도 고를 수 있음 — 높이는 그대로라 해롭지는 않음)
  - 잔디와 돌 비율: 돌 길이 잔디를 다 가르면 돌밭으로 보임 → 잔디를 넓게, 길은 디딤돌로 (시안 고침). 전망대에서 난간 너머로는 섬 바닥이 안 보임 → 발밑 유리 바닥 고리로
  - **들여다보는 망원경** (`InteriorTelescope`, 중력 거주구 · 아콜로지): 받침은 Shell, 머리 (경통 · 렌즈 · 접안경)만 따로 `INT_*_Scope` — 회전 중심은 받침 공 위, 쉴 때 자세 = 바깥쪽으로 들린 그대로 모델링 (`Configure`의 restYaw · restTilt와 같게). 난간 곁에 둘 땐 머리가 숙여도 (−18°) 난간 위로 지나가게 높이를 맞추고, 머리는 어느 쪽으로도 돌 수 있으니 회전 중심에서 경통 끝까지 거리만큼 길을 비움. 바깥 모델 안에서 내다보는 곳 (알 속)은 들어 올림 0 — 자기 바깥 모델은 카메라를 품어 자동으로 숨겨짐
  - **빈 칸을 품은 모듈의 하늘 껍질 = 전체를 감싼 큰 상자** (첫 사용 = 대형 토러스 `gt_builder`, 안쪽 빈 칸 넷): 차지한 칸만 둘러싸면 빈 칸 벽이 허브 · 건너편을 다 가림 (껍질은 바깥 화면을 그릴 뿐 어디 있든 같은 그림이라 멀리 둬도 됨). 대형 토러스 내부 고리 안쪽 끝은 r 13.55라 빈 칸 모서리 (r 16.97) 안으로 3.4m 들어옴 (외형 고리도 조금 들어옴, 폭 6m에 산책로 · 집 · 고가를 넣으려고). 그 칸의 모듈이 다른 길로 이어져 함께 켜지면 겹쳐 보일 수 있음
  - **여러 겹 겹치는 큰 유리 = `M_InteriorEvo2ClearGlass`** (대형 토러스): 유리 지붕 + 벽 + 창을 지나 바깥을 보면 `Evo2Glass` · 알 유리는 초록으로 탁해지고 환경 반사의 지평선이 창에 비치며, 가까운 등불에 물들어 지붕이 청록으로 빛남 → 환경 반사 · 하이라이트 끄고 어두운 색 · 알파 0.07. 난간 유리는 그대로 Evo2Glass (보여야 안 부딪힘)
  - **아치 벽 `arch_wall`** (`gt_builder`, 고리 전체를 칸마다 아치로): 칸 둘레 점을 고정 (이웃 칸과 옆 꼭짓점이 같음)하고 가운데서 나가는 광선으로 구멍 윤곽을 잡아 잇는다 — 불리언 72번 대신. 옆 분할이 적으면 아치 어깨가 각지므로 위쪽 옆 분할을 촘촘히
  - **타는 열차** (`InteriorTrain`, 대형 토러스): 조각 원점 = 템플릿 원점, 허브 축 피벗 아래로 옮겨 통째로 돌림 (휜 객차도 그대로). 칸 높이 8m 안에 고가 아래 회랑 (바닥 + 2.42) + 갑판 + 열차 (지붕 y 3.83, 칸 위 경계 4)가 들어가게 높이부터 잼. **열차 폭이 고가 벽에 닿는지 먼저 계산** (시안에서 5cm 겹쳤음), 표준 소켓 3.2면 문 패널이 선로로 들어옴 → 고가 바로 뒤 문은 소켓 깊이 3.9 (Sky 조각 · 구멍도 그 자리에). 선로 쪽은 스크린 도어로 막아 플레이어가 선로에 못 들어가게. **객차 바닥을 승강장보다 7cm 높임** — 주민 `FloorFree`는 같은 높이(±6cm) 바닥만 고르므로 열린 문으로 열차에 올라타지 않음 (플레이어는 턱을 그대로 넘음). 움직이는 조각에 `Screen` 재질 금지 (상태 화면이 제자리에 떠 있게 됨)
  - **사분면을 돌려 만들 때 방향 부호** (대형 토러스): rot_y 기준 forward = (sin yaw, cos yaw)라 남쪽 사분면 az = 270 + s·th에서 바깥 yaw = 180 − s·th, 안쪽 yaw = −s·th. 180 + s·th로 쓰면 곡선을 따라야 할 집 · 벤치가 2th만큼 비틀림 (평면도에서 집이 X자로 겹쳐 보여 발견). 이웃 사분면과 끝점이 같은 바닥은 끝을 0.3° 줄임 (같은 꼭짓점 병합으로 비다양체)
  - **내부도 외형 모양 그대로** (대형 토러스, 사용자 2026-11-03 플레이 의견으로 다시 짬): 외형이 원형이면 내부에 네모 광장 · 곧은 유리벽 · 바깥으로 튀어나온 현관 · 떠 있는 상자 집을 두지 않음 (평면도를 위에서 찍어 외형과 견줌). 대표 건물 (시계탑)은 멀리서 봐도 같은 실루엣이 되게 몸통 · 지붕 비율까지 맞춤. 플레이어는 늘 아래에서 올려다보므로 **지붕을 좁히고 첨탑을 가파르게** (넓은 지붕이 첨탑을 가림)
  - **한쪽에서만 보이는 시계판** (`one_way_disc` · `one_way_quad`, 대형 토러스): 닫힌 덩어리가 아니라 면 방향을 직접 맞춘 판 → 뒷면이 안 그려져 밖에서는 불투명한 흰 시계, 안에서는 맑은 창. 바깥 눈금 · 바늘도 같은 판으로 (두께 있는 판이면 안에서 이중으로 보임). 충돌체 없는 조각 이름 (`_DialFace`), 뒤에 맑은 유리 + 충돌체. 비다양체 검사 대상에서 뺌
  - **아치 구멍 윤곽 모서리 고정** (`arch_wall`): 가운데서 나가는 광선만으로 구멍을 잡으면 네모 아래 모서리에 꼭짓점이 없어 옆면이 바닥 쪽에서 비스듬히 좁아짐 (경사판처럼 보여 "이음새가 이상함"의 하나) → 칸 아래 두 모서리를 구멍 모서리 (±폭, 아래 y)에 직접 잇기. 구멍 없는 칸은 `hw = 0` (칸막이가 지나는 자리 · 집 뒤, 창이 반쪽으로 잘리지 않게)
  - **고가 · 곡면 벽과 곧은 문이 어긋나는 자리**: 곡면이 비스듬히 지나는 문 자리는 유리 현관 말고 짧은 불투명 문간 + 소켓 깊이 조정 (고가 바깥 곡면 뒤로 패널을 들임), 문간 천장에 등. 하늘 구멍도 같이 옮김
  - **층계참 → 승강장 틈을 각도로 재기** (대형 토러스): 계단 끝 각 ~ 끝 난간 사이 틈 = 반지름 × 각. 시안 26° · 계단 끝 23.9°로 46cm여서 캡슐이 못 지나감 → 걷기 시험 경로는 **층계참 가운데를 지나는 폭 1.2m 캡슐**로도 쓸어 봄. 곧은 "스트리트" 시험만으로는 안 드러남
