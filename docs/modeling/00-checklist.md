# 모델링 체크리스트 — 모델링 전 · 내보내기 전마다 처음부터 끝까지

> MODELING.md를 나누며 모든 절에서 뽑은 꼭 볼 규칙 (2026-11-11, 사용자 요청 — 한 파일이 길어 규칙을 놓침). 한 줄 = 한 규칙, 괄호 = (확인 방법 / 상세). 자동 = 스크립트 · 테스트, 눈 = 사진. 상세 = 이 폴더 파일 앞 번호 (01 geometry · 02 space · 03 animals-props-plants · 04 exterior · 05 interior-templates · 06a · 06b · 06c evo-interiors · 08 verification) + 절 또는 모듈 이름.
> 대괄호 = 그 종류에만 (외형 = 바깥 모듈 모델 · 진화 = 진화 모듈 내부 · 개방형 = 2단계 개방형 방 · 실내형 = 지붕 · 유리 안 방 · 3단계 · 후룸), 표시 없음 = 공통 (주로 내부 키트 · 템플릿 · 소품). 새 문제를 겪으면 주제 파일에 자세히 적고 여기에 한 줄 더함.

## 면 · 메시
1. 면은 덩어리마다 바깥을 향하게 (따로 뒤집지 않음 — FBX · Unity가 처리), 방향은 부호 있는 부피로 (`int_common.orient_outward` · 외형 `orient_parts`, 무게중심 기준 double) — `recalc_face_normals`를 믿지 않음 (자동: `check` 뒤집힌 덩어리 0 · Unity 덩어리별 부호 있는 부피 / 01 §1 · §5, 04 §7-7, 05)
2. 베벨 뒤 새 면 재질 재지정 + 감김 통일, `soft_box` 둥근 반지름 < 가장 짧은 변의 절반 (자동: `check` 비다양체 0 / 01 §2)
3. 서로 다른 조각의 면이 같은 평면에 겹치지 않게 — 보이는 쪽 0.002 비킴 · 바닥 판 0.003 띄움 · 줄무늬는 칸을 번갈아 한 높이로, 잘 생기는 곳 = 같은 폭 띠 끝면 · 상판 + 띠 · 문틀 + 머리 · 바닥 문양 + 깔개 (5mm 좁히거나 넓힘) (자동: `overlap_check.overlaps` / 01 §3, 05)
4. 같은 치수로 맞닿는 꼭짓점 (번갈아 잇는 칸 · 네온 막대 · 같은 반지름 고리 · 쌓는 회전체 축 점 · 사분면 끝점)은 0.001 ~ 0.006 엇갈림 — `clean` 점 병합(0.5mm)이 붙여 비다양체 (자동: `check` / 01 §3, 04 §7-7, 06a · 06b · 06c)
5. 가장자리를 맞대기만 하지 않고 한쪽을 뒤로 겹침 (상자 0.01 · 조립 토막 0.002 · 문틀은 인방 속 3cm) — 이음선 틈 · 비다양체 (자동: `check` · 눈: 이음선 / 01 §4, 03 §7-6, 05, 06a)
6. 불리언 cutter는 잘리는 면 너머 안 보이는 부피(바닥판 · 천장판 · 벽 속)까지, 속 공간(cavity)은 바깥 덩어리 안에 — 닫힌 구멍은 경계 검사로 안 잡힘 (자동: Unity 뚫림 / 01 §5)
7. 합치는 덩어리끼리 · 빼는 cutter끼리 같은 평면을 공유하지 않음 (0.02 ~ 0.1 엇갈림) — 바닥이 같은 cutter를 합쳤다가 단이 통째로 지워졌는데 검사는 통과, 산을 파는 cutter는 먼저 합쳐 한 번에 빼고 바로 `clean` (눈: 빌드 뒤 사진 / 01 §5, 06c 자르개 · 궤도 도시)
8. 자르는 상자를 같은 평면에서 맞대지 않음 (두께 없는 판이 남아 안 보이는데 길을 막음), 꽉 찬 덩어리에서 빼서는 구멍이 안 뚫림 → 그 자리 면을 지움 (자동: 걷기 · 옆에서 쏜 광선 · `SkyShellIsOpenAtEveryDoor` / 06c 차폐벽 · 코드 검토)
9. 내보내기 전 `clean()`, 굽지 않는 부품(FX · 도는 부품)도 n각형 삼각형화, 오목 뚜껑은 삼각형화 전 `bm.normal_update()` (자동: Unity 콘솔 "self-intersecting polygon" 0 / 01 §5, 04 §7-7 · §7-9)
10. 가는 관 · 작은 회전체 · 곡선 관(터널 안면)은 Shell에 넣지 않음 → Soft · 따로 덩어리, 바퀴살은 중심에서 1cm 띄움, 두꺼운 잎은 `om_builder._leaf` (자동: `check` / 05, 06b, 06c)
11. 천장 · 바닥에 붙은 얇은 돌출의 옆면은 비스듬히 (`frustum_band`) — 수직면은 새까만 틈 (눈: 올려다본 사진 / 01 §6)
12. `lathe`는 끝을 막고 축까지 막음 → 속이 빈 탑 · 천장 구멍 유리 돔 · 샤프트 지나는 바닥은 `lathe_loop`, 평평한 윗면은 `crisp(lathe(...))` [진화] (자동: 구멍 안 천장 높이 Window 면 0개 · 축 근처에서 위로 쏜 광선 / 06a 유리 돔, 06b, 06c 실드 돔)
13. 글꼴 글자 · 양면 부품은 `fix_caps` + Unity에서 앞뒤 렌더 (Blender 미리보기는 뒷면도 그림), 잘게 나눈 곡면만 `use_smooth` [외형] (눈: Unity 앞뒤 / 04 §7-7)
14. 숨긴 레이어 컬렉션이 있으면 `join`이 조용히 실패 → `INT_*` 보이게 · 지역 보기 해제, append한 텍스트 블록은 `use_fake_user` 뒤 저장 · 다시 열어 확인 (눈: 면 수 / 05)

## 배치 · 겹침
15. 문 자리 예약 구역 비움 — 수평 문마다 가로 ±1.7 · 벽면에서 안쪽 0.45 · 높이 F ~ F + 3.75, 벽기둥 머리 · 구석 의자도 이 밖 (자동: `overlap_check.door_zone` 빈 목록 / 02 §7, 05, 08 §2-1)
16. 문 구멍 = 키트 패널(3.2 × 4)보다 양쪽 JAMB 0.06 좁게 + 바닥판도 벽면 − 0.1부터, 천장이 F + 3.6보다 높으면 구멍은 패널 높이(F + 3.74 ~ 3.78)까지 · 문 벽은 F + 3.85까지 곧게 (자동: Unity 뚫림 · 키트 ↔ 템플릿 같은 평면 / 01 §1 · §4, 06a)
17. 키트 문 패널(±1.6, 벽면에서 0.4) 밖으로 키트 조각 · 고리가 나오지 않게, 패널 옆 장비 디테일은 벽에서 0.5 이상 · 그 사이는 닫힌 면, 둘레 띠 · 몰딩 · 홈 빛줄은 문 자리에서 자르고 F + 3.78보다 충분히 아래 (눈: 문 자리 가장자리 / 02 §7, 06a)
18. 소품이 벽을 뚫지 않게 — 회전 소품은 가장 멀리 뻗는 끝까지 재고, 벽 묻힘 ≤ 0.03, 벽 가까운 화분은 잎 폭을 재서 줄임 (자동: `overlap_check.wall_poke` / 02 §7, 03 §7-5)
19. 모델은 자기 칸 안에 (옆 0.06 · 위 2m) — 오목 모서리 둥글림 ≤ 0.12, 칸 끝 처마, 문 깊이마다 붙는 키트 조각, 문 패널에 칸 밖으로 나가는 조각 금지 (자동: `InteriorTemplateBoundsTests` / 06b 치안 본부, 06c 모델은 자기 칸 안에, 08 §13)
20. 떠 있는 조각 없음 — 손잡이 · 코일 · 등받이 · 받침 · 구슬 · 바퀴 · 재배등은 받침 속 1 ~ 2cm, 벽 판 = 벽 앞면 + 0.010, 둥근 받침 둘레 기둥은 반지름을 따로 대조 (자동: `interior_scan.floating` / 05, 06b 작은 장식, 06c 회전목마, 08 §7)
21. 기운 판은 낮은 모서리를 윗면에 맞춤 · 선반 위 둥근 소품은 아랫면을 자름 · 곡면 위엔 휜 판, 통에 꽂는 판은 위가 열린 통의 더미 속 (자동: 판 꼭짓점 최저 ≥ 윗면 / 01 §6-1, 05)
22. 열리는 면 앞 0.8 비움, 경첩 문 · 엘리베이터 문짝은 닫힘 ~ 열림 전 범위에서 다른 조각 · 호출 버튼과 안 겹침 (자동: 각도별 BVH 겹침 / 02 §7, 05, 06b 치안 본부, 06c)
23. 움직이는 장치(톱니 · 크레인 · 스태커 · 태양 패널 · 눕는 등받이 · 탈것 · 회전목마)는 움직이는 전 범위의 꼭짓점을 재서 벽 · 유리 · 고리 · 실은 물건과 안 겹치게 (자동: `civ_recline_check` · `ct_sweep_bvh` · `CargoFlumeCourseTests` · `StorageCarouselTests` / 02 §7, 06a, 06b, 06c)
24. 기울인 콘솔 · 화면은 서는 쪽을 봄 (`obox` rx 부호 = 벽 방향, 상자 · 화면 법선은 같은 식), 창 아래 가구는 벽과 나란히 · 창턱 앞 0.05, 쌓는 물건은 모서리 맞춤 + 0.002 틈, 나란한 같은 가구 = 몸통 하나 + 칸마다 문, 둘레 배치 간격 = 360 / 개수 (눈: 콘솔 앞 · 평면도 / 02 §7, 05, 06b 아콜로지)
25. 식물이 물체를 파고들지 않게 — 흙 윗면은 재배대 윗면 아래 · Tree 화분 안 테 ≥ 0.75 × 크기 · 시안 나무는 게임 모델(`SM_PlantTree`)로 놓고 유리까지 거리를 잼 · 구경 자리가 나무 속에 들지 않게 (눈: 시안 · 플레이 사진 / 03 §7-5, 06a, 06b 바이오돔 · 아콜로지)
26. 해치 — 틀 1.9 · 뚜껑 1.4가 칸 가운데 ±3m 안 평평한 1.6m에 (축 방향), 틀이 벽기둥 · 난간 · 벤치와 안 겹침, 도착점 = 뚜껑 중심 + 앞 1.1m, 파 내려간 객석 칸엔 금지 (눈: 위에서 본 평면 / 05, 06b 시민 회관, 06c 바이오스피어)
27. 맨 벽(0.72 × 0.68m 평평한 면) 한두 곳 남김 (벽 소품 자리), 화면은 평평한 사각 판 0.18 × 0.1m 이상 · 앞 45cm 비움 (자동: `InteriorSpots` · `InteriorStatusScreens`가 잡는지 / 05, 06a)
28. 앉는 가구 = `_Shell` · `_Soft` 충돌체, 의자 앞 끝 = 엉덩이 + 0.07, 꼬리 · 귀를 크게 돌릴 때 머리 · 등받이와 안 닿게 (자동: 08 §9 · §10 · 눈: 여우 앞 · 옆 / 03 §7-1, 06a, 06b 식량 공장)

## 걷기 · 동선
29. 길부터 비움 — 플레이어 반지름 0.3 · 키 1.75 (살갗 포함 1.83), 주민도 단단한 충돌체, 길 폭 1.3m 이상, 통로 띠에 가구 · 러그 금지, 길 중간 짧은 턱 벽 금지, 문 · 엘리베이터는 안쪽까지 지나가 봄 (자동: 걷기 지도 · `CapsuleCastAll` / 06a, 06b, 06c 미로, 08 §14)
30. 머리 높이 위 장식 · 깃발 줄 · 전구 줄은 충돌체 없는 조각 (`Bunting` 등), 낮은 천장 · 아치 아래는 실제 키로 걸음 (자동: 실제 키 걷기 / 06b 시민 회관, 06c 요새 포대)
31. 2 ~ 3cm 낮은 판(디딤돌 · 판자 길)은 충돌 없는 `_Lawn`, 물은 `_LakeHit`로 막음, 화분 없는 나무는 줄기 캡슐 [개방형] (자동: 08 §13 야외 공간 / 06b 바이오돔)
32. 계단 — 아래 끝 옆에 평지 · 난간은 첫 단부터 · 옹벽을 따라 휨, 나선 계단은 층계참 끝 머리 공간 (r 0.5 · 0.8 · 1.15를 오르고 내려옴), 층계참 → 승강장 틈 = 반지름 × 각 [진화] (자동: 걷기 · 폭 1.2m 캡슐 / 06b 대형 토러스, 06c)
33. 엘리베이터 — 샤프트 · 탑 구멍 높이의 판(지붕 테두리 등)도 모두 자름, 샤프트를 두른 고리 · 띠는 문 자리를 비운 부채꼴, 호출 판 = 문 옆 기둥 앞면 · 칸 안 판 = 들어가면 보이는 옆 벽 [진화] (자동: `InteriorLiftShaftTests` · 버튼 조준 / 06a, 06b 치안 본부 · 식량 공장, 08 §11)
34. 난간 — 손잡이 끝을 기둥 · 다음 난간 속에, 끊김 없는지 평면 확인, 틈은 잘라서 (`rail_path`), 열린 줄은 `closed=False`, 울타리는 받침 테 위 (자동: 걷기 · 눈: 평면도 / 06a, 06b, 06c)
35. 난간은 경계가 아님 → 칸 경계 `OpenAirBarrier` · 옥상 `RoofFence` · 주민 `NoClimb`, 옥상이 실내로 잡히면 `SetIndoorBox` [개방형] (자동: 벤치 · 등받이 밟고 넘기 / 06c)
36. 주민 자리 수 = 들어오는 주민 수 (5칸 25자리), 폭 1.5m 이하 길 · 좁은 데크엔 서는 자리 금지, 관람석은 맨 아랫줄만, 스폰 앞을 지나는 주민 길 금지 (눈: 플레이 / 05, 06b, 06c)
37. 탈것 — 곤돌라 문틀 > 1.83 · 객차 바닥 = 승강장 + 7cm · 선로는 스크린 도어 · 움직이는 조각에 `Screen` 금지 · 복제를 다 한 뒤 짐 싣기 (자동: 탑승 시험 / 06b 대형 토러스 · 식량 공장, 06c 후룸)

## 물 · 연출 · 빛 · 재질
38. 물 = 수면 높이마다 따로 물체 (`Water` · `Water1` …, KWS 기준점 = 수면), 물 밑면은 땅 · 둑에 묻음 [3단계] (눈: 물이 뜨지 않는지 / 04 §7-10, 06c 궤도 도시)
39. 폭포 — 웅덩이 반지름 ≥ 물줄기 폭 + 0.1 · 위 단 옹벽 밑에 붙임, 물길 홈 끝은 수면 바로 아래까지 넘침돌, 물줄기 판 UV (v 아래로), 거품은 Unity 입자 (눈: 폭포 정면 · 옆 / 06c 궤도 도시)
40. 물길 입구 — 물통을 못 안쪽 면으로 잘라 벽 안면에 맞춤, 네모 못 끝벽은 늘리지 말고 벽 선을 맞춤, 물 띠는 못 물보다 1cm 낮게 [후룸] (자동: `ct_sweep_bvh` · `ct_holes` / 06c 물길 탈것)
41. 통 · 수조 속 물 = 반투명 물 덩어리 `WaterClear` + 수위 테 (얇은 물 면 판 금지), 내부 물 · 폭포 재질은 윤슬 0, 밝은 돌은 `Evo2Rock` (눈 / 06a, 06b 바이오돔)
42. 연출은 메시로 굽지 않음 — 용접 `InteriorFx.Spark` + 닿은 토치, 빛줄기 `LightBeamFx` (가는 관 금지), 번개 `LightningFx`, 오로라 · 은하수 셰이더, 홍염 `SolarFlare`, 연기 · 스파크엔 원인 물건, 연출 면은 몸체에서 2mm 이상 (눈 / 01 §6-1, 03 §7-4, 04 §7-9, 06b, 06c)
43. 점광원 금지 자리 — 화면 바로 앞 · 발광 구 바로 아래 · 도는 부품 길 · 금속 지붕 근처 · 돔 꼭대기 테 1.3m 안, 색 점광원은 꼭 필요할 때만, 파손 방 불빛 0.2 ~ 0.3 · 깜박임 금지 (자동: 캡처 포화 픽셀 0 · 눈: 반사점 / 03 §7-4, 05, 06a, 06b, 06c)
44. 재질 — 벽 재질(Hull · HullDark)은 벽 · 바닥 · 천장 · 큰 기계 몸통만, 천 = Fabric · Blanket, 화면 재질은 화면만, 소품 색은 발광 없는 `Prop*` · `Paint`, 큰 면에 Accent · Light 금지 (눈 / 01 §6-1, 02 §7, 05, 06c)
