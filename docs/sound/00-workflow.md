# 사운드 작업 지침 (2026-11-20 — 내부 문 소리 작업에서 정한 방식)

> 사용자 2026-11-20 "문 여닫이 소리 만들면서 했던 작업 방식을 주요 지침으로 남겨 두고 이후 사운드 작업할 때 사용하자".
> 사운드 작업(새 소리 · 교체 · 음량 조정)을 시작하기 전에 **이 문서를 처음부터 끝까지** 읽는다. 무엇을 만들지는 `SOUND_LIST_NEW.md`(목록 · 세팅 디테일 D-1 ~ D-14 · 3단계 D-7b).
> 새로 겪은 문제는 맨 아래 "겪은 일"에 한 줄씩 더한다.

## 0. 역할 나눔

- **Claude가 고른다** — 사용자에게 후보를 들려 주고 고르게 하지 않는다 (사용자 "들어서 판단하기엔 사운드적 소양이 모자람"). Claude는 소리를 들을 수 없으므로 **그림(스펙트로그램) + 수치**로 판단한다.
- **사용자는 게임 안에서 듣고** 과한지 · 어색한지 · 느낌이 맞는지만 말한다. 그 말을 원인(수치)으로 바꿔 고친다.
- VARCO 결과는 **묻지 않고 바로 내려받아** 진행하고, 그 소리 처리가 끝나면 남은 후보는 지운다 (사용자 2026-11-20).
- **사용자가 정할 것은 그때 묻지 않고 `docs/sound/decisions.md`에 모은다** (질문 · 배경 · 선택지 + 추천 · 들어 볼 곳) → 사운드 작업 마지막에 질문 형식으로 하나씩 묻고, 답은 그 문서 "정한 것"으로 옮겨 반영 (사용자 2026-11-25). 하위 작업자의 "정할 것"도 검수 때 이 문서로 옮김.

## 1. 방향 먼저 (만들기 전)

1. **게임 톤 = 아기자기**: 무겁고 날 선 소리(쾅 · 철컥 · 쇳소리 · 굉음)는 피하고 둥글고 가벼운 쪽(툭 · 톡 · 슉 · 퐁). 단, 단계 테마의 무게는 살림 — 기본 모듈 = 산업 단지 느낌으로 **조금 묵직하게**(먹먹한 "쿵"), 1단계 = 매끄러운 전자, 2단계 = 밝음, 3단계 = 유리 · 자연.
2. **한 물건 = 소리 하나**가 기본 (사용자 "하나로 통일"): 문처럼 정체성이 있는 물건은 열림 · 닫힘 각각 하나만 쓰고, 반복감은 재생 때 음높이 ±3 %로만. 성격이 다른 후보를 섞어 돌리면 "가끔 다른 문"처럼 들림.
   - 예외: 초 단위로 몰리는 소리(발소리 · 클릭 · 스파크)는 같은 녹음의 다른 순간을 여러 개 (발소리 9걸음 — 한 사람의 걸음).
3. **언제 · 어디서 나는지**: 동작 시간(문 = 0.25초에 열리고 닫힘)에 맞춰 소리 구조를 정함 — 바로 시작, 부딪힘은 동작이 끝나는 순간, 1초 안팎.
4. **지금 있는 방 소리만**: 내부에서 방 바탕 · 물체 · 주민 소리는 플레이어가 있는 방 것만. 다른 방은 사고 · 파손 · 습격 같은 상황 알림만 (먹먹하게 + 방향).

## 2. 만들기 (VARCO)

- `varco_text_to_sound` 한 번에 후보 5개 (값 = 한 번 50 크레딧, 링크 1시간).
- **프롬프트 = 무엇 + 느낌 + 빼고 싶은 것**: 예) `industrial sliding metal door closing, slightly heavy but soft muffled thud at the end, short air hiss, solid and weighty, no metallic ringing, no harsh clang, cozy game`. 아기자기 쪽은 soft · gentle · cute · cozy · rounded, 무게가 필요하면 weighty · muffled · solid. 쇳소리가 나기 쉬운 소리는 **no metallic ringing**, 세게 치는 소리는 **no harsh clang / no harsh impact**를 꼭 넣음.
- **순서대로 하나씩 만들어 비교한다** (사용자 2026-11-23 "한 번에 너무 많이 뽑는다고 연락을 받음 — 순차적으로 제작해서 비교"): 한 번에 생성 호출 **하나**(효과음 = 후보 5개, 음악 = 2곡)만 돌리고, 받아서 재고(그림 · 수치) 고를 게 있으면 멈춤. 없으면 무엇이 모자란지(날 섬 · 빠르기 · 조 · 끊김 등)를 프롬프트에 고쳐 넣고 다음 하나. 여러 프롬프트를 동시에 돌리지 않음. (문 닫힘은 3번: 묵직한 쾅 → 부드러운 툭 → 조금 묵직한 쿵. 11-23 내부 음악 때 한 번에 수십 곡을 돌렸다가 이 규칙이 생김.)
- 음악 = `varco_music_generate` (한 번에 약 3분 두 곡, mp3). 이 PC엔 ffmpeg가 없으므로 `AudioOriginals/tools/decode.py`(Blender `-b`로 실행, aud 모듈)로 wav로 풀고 `music_check.py`로 판정 (빠르기 · 조 · 고름 · 루프 자리) + `calm_check.py`로 차분함 (어택/초 · 고음 어택 · 무게중심 · 300 Hz 아래 — 바깥 곡과 나란히 재서 비교).
- 받는 곳 = `AudioOriginals/_candidates/<묶음>/` (git 제외). 음악(mp3)은 효과음 다듬기 도구(`varco_variation` 등)에 넣지 않음.

## 3. 고르기 (그림 + 수치)

도구 (Blender 내장 파이썬 `"C:/Program Files/Blender Foundation/Blender 5.2/5.2/python/bin/python.exe" -I`):
- `AudioOriginals/tools/audition.py <wav 폴더> <그림 폴더> [초]` — 이름 앞부분으로 묶어 묶음마다 스펙트로그램 판 + 수치(무게중심 · 300 Hz 아래 / 4 kHz 위 비율 · 잡음 바닥 · 꼬리 · 잡음스러움 · tonal).
- `AudioOriginals/tools/audit.py <폴더>` (`PYTHONIOENCODING=utf-8`) — crest · attack · crackle · tonal · mid1-6k · ring.

판 읽기: 가로 = 시간 (초록 세로선 0.25 · 0.5 · 1초), 세로 = 50 Hz ~ 16 kHz, 밝을수록 셈, 흰 점선 = 소리 크기. **꼭대기까지 뻗는 밝은 세로줄 = 날 선 부딪힘**, **가로로 길게 남는 가는 줄 = 쇳소리 울림 · 삐**.

탈락 기준:
| 걸리는 것 | 기준 | 겪은 예 |
|---|---|---|
| 시간 구조가 안 맞음 | 시작 전 빈 곳 · 부딪힘이 여러 번 · 쓸데없이 긴 꼬리 | 3초 뒤 또 부딪힘, 꼬리 3.6초 |
| 의도한 구성이 없음 | 예: 문 = 철컥 + 치익인데 치익만 2초 | 기본 문 열림 1 · 4 |
| 날 섬 | crest(50 ms 대비 순간 최고) 높음 · attack 2 ms 아래 · 판에 꼭대기까지 밝은 세로줄 | 처음 "쾅" |
| 찰랑 (쇳소리 울림) | `ring` 5 넘음 — 0.8 ~ 12 kHz 좁은 울림이 0.1초 넘게 | 2391 Hz · 4.2 / 8 kHz |
| 통통 · 웅 | `tonal` 4.5 넘음 | 1차 합성 발소리 6 ~ 7.7 |
| 지직 | 계속 깔리는 소리에 고음 잡음 터짐 (`crackle` · 판의 잔 세로줄) | 1차 전기 방 · 고열 방 |
| 잡음 · 이상한 끊김 | 잡음 바닥 −40 dB 위, 소리 중간에 디지털 무음 | 부드러운 후보 A1 |
| 무게가 단계와 안 맞음 | 300 Hz 아래 비율 · 무게중심 | 묵직하게 = 300 Hz 아래 80 % 넘게 |
| 발소리에 닿는 소리 없음 | 뒤꿈치 · 앞꿈치 "탁"이 판에서 높은 소리까지 뻗어야 | 1차 합성 발소리 |

고른 이유는 `build_audio2.py` 그 묶음 주석에 한 줄씩 (다른 후보를 뺀 이유까지).

## 4. 다듬기 (`AudioOriginals/build_audio2.py`)

- 2차 소리는 **이 스크립트에만** 더함 (1차 `build_audio.py`를 다시 돌리면 1차 66개가 전부 새로 만들어짐). 고른 원본은 `AudioOriginals/<묶음>/`에 보관(git), 1차 결과를 손볼 땐 `Interior/legacy/`에 보관해 거기서 다시 만듦 (몇 번 돌려도 같은 결과).
- 도구:
  - `trim_lead` 앞 빈 곳 자르기 · `fade` · `highpass` (50 ~ 80 Hz 아래 정리)
  - `hit_time` + `hit_at(x, hit, at, length, fout)` — **부딪힘을 동작 순간에 맞춤** (문 = 0.25초). 커지는 데 시간이 걸리는 둥근 소리는 시작이 동작 순간에 오게 at을 늦춤 (묵직한 쿵 = at 0.36).
  - `tame(x, dB)` — 가장 센 부분만 눌러 덜 치고 나오게 (쾅 7 dB, 철컥 6 dB, 묵직하게 남길 땐 3 dB)
  - `soften(x, fc, amount)` — 날 끝(4 ~ 5 kHz 위)을 둥글게 (원본 65 % + 로우패스라 고음이 3 dB 남짓밖에 안 줆 — 배경 쉬—를 걷는 데는 못 씀)
  - `notch(x, f)` — 좁은 울림 하나만 깎음 (찰랑). 깎아도 ring이 5 넘게 남으면 **그 후보를 뺌**.
  - `circular(fn, x)` — 루프는 끝을 앞에 붙여 필터 (이음새 유지)
- 음량 = `save(rel, x, target_db)` (50 ms 최대 크기 기준). 처음 값은 비슷한 소리를 따르고, 6번 녹음 검수로 맞춤.
- **루프 고음 상한 (자동, 2026-11-23)**: `save`가 `_loop.wav`마다 `match_tilt`를 거침 — 4k · 8k · 16k 옥타브가 몸통 띠 (250 ~ 2k 중 가장 큰 옥타브) 기준 −10 · −22 · −34 dB를 넘는 만큼만 고정 EQ로 낮춤 (원형 FFT라 이음새 그대로, 넘는 띠가 없으면 그대로). 내부 음악은 4k −30 · 8k −38 dB로 어두워서 그 위에 고른 쉬—가 얹히면 잡음으로 들림. 고음이 소리 자체인 루프 (풀벌레 · 잎 · 신호 잡음 · 태양 폭풍)는 `TILT` 표에 예외 · 덜 낮춤으로. 한 번 소리는 꼬리 바닥 −60 dBFS 아래 · 꼬리에 쉬— 없게 (`fade` + 높은 쪽 누르기).
- 다듬은 뒤 **판으로 다시 확인**: 자른 자리 · 부딪힘이 동작 순간에 오는지 · 꼬리 · 세로줄 · 가로줄.

## 5. 연결

- `SoundLibrary`에 칸 (묶음별 Header + Tooltip에 결정 이유), `AudioSetup` 이름표(칸 → 파일 앞부분)에도 추가.
- 클립 연결은 RunCommand로 `SoundLibrary.asset`의 그 칸만 (메뉴 `SpaceStation/Audio/Setup`은 열린 장면까지 다시 연결하므로 메뉴 장면에서 돌리면 위험).
- 내부 물건 소리 = `AudioService.PlayAt` / `TryPlayAt` (그 자리 3D, 2 m까지 그대로 → 15 m에서 0). UI · 음악 · 내 발소리 · 알림은 2D.
- 반복 막기 (D-2): 같은 때 여러 개 = 한 번 · 자동 처리는 무음 · 같은 자리 반복(문간)은 거리 차이(열림 2.2 m / 닫힘 2.7 m) + 최소 간격.

## 6. 게임 안 녹음 검수 (`ListenerTap`)

메인 카메라(리스너)에 `ListenerTap`을 붙여 실제로 들리는 소리를 녹음 → `AudioOriginals/tools/rec_check.py <녹음> 0.5-3:이름 ...`로 구간별 크기 · jump · crackle · 대역.

- **크기 기준**: 한 번 나는 소리는 그 방 바탕 위 **4 ~ 6 dB** (50 ms 최대 − 바탕 중앙값). 너무 크면 튀어나옴, 3 dB 아래면 묻힘. 음악이 겹치는 때에 따라 흔들리므로 2 ~ 3번 재서 평균.
- **누가 내는 소리인지 가리기**: 깔리는 소리(정거장 험 · 음악 · 방 바탕)를 하나씩 `mute` 하며 4초씩 녹음해 비교.
- **플레이 자동화** (Unity가 뒤에 있어도 됨):
  - Main 장면 열고 플레이 → `sim.TryPlace(MD_Battery, (-1,0,0))` → `InteriorMode.Enter(sim.Core)` → 문(배터리 칸에 가장 가까운 `InteriorDoor`) 앞뒤로 `Teleport` (1.2 m = 열림, 3.1 m = 닫힘).
  - 걷기 = `InputSystem.onBeforeUpdate`에서 `InputState.Change(Keyboard.current, new KeyboardState(Key.W))` (키 하나만 바꾸는 `Keyboard.current[Key.W]`는 bitfield 오류). 훅은 기한을 두고 스스로 빠지게 · 오류가 나면 `EditorUtility.RequestScriptReload()`로 남은 훅 정리.
  - 녹음 시점은 `EditorApplication.update` 훅 + `Time.realtimeSinceStartup`. 확인 뒤 플레이 멈추고 메뉴 장면으로 되돌림. 플레이 중엔 .cs를 고치지 않음.
- 기존 소리도 같은 기준으로 한 번씩 (`audit.py` 전체 표 — 정비 · 회전 딸깍처럼 걸린 것은 교체 때 같이).
